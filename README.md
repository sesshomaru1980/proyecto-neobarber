# NeoBarber

Sistema web para la gestión de barberías y reservas de citas.

## Tecnologías

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Base de datos
- MongoDB

### Seguridad
- JWT
- bcrypt

## Roles

- Administrador
- Barbero
- Cliente

## Funcionalidades

- Gestión de servicios
- Gestión de barberos
- Gestión de citas
- Agenda de barberos
- Control de acceso por roles
